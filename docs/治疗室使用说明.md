# 治疗室使用说明

这份说明写给每天用它的治疗师和助手，不涉及开发。开发相关看 README.md。

## 每天开始：打开派工单

1. 打开治疗室电脑（或常开的小主机）。开机后自动进入系统即可，不用别的操作。
2. 打开一个终端，进入项目目录，运行：

   ```bash
   npm start
   ```

3. 终端会打印类似 `clinic api http://192.168.1.5:8787` 的地址。
   电脑上用 `http://127.0.0.1:8787/`，手机连**同一个 Wi‑Fi**，浏览器打开 `http://192.168.1.5:8787/`（以终端打印的为准）。
4. 手机上建议「添加到主屏幕」，之后一点就开。第一次打开会下载人体模型（几 MB），之后有缓存，秒开。

关机不需要任何操作，数据都在电脑的 `data/clinic.json` 里。中途断电也不会丢掉已保存的内容。

## 第一次使用：认人

- 第一台打开的手机**写下自己的名字**，进入今日单。
- 其余手机从名单里点「我是谁」，或填新名字。之后这台手机记住这个人，直接进今日单。
- 手机弄丢了或换人了：设置里把那台手机换绑到新名字即可。

## 日常流程

### 病人来了，加入今天

今日单底部「加入病人」：

- **老病人照旧做**：病人名下面有「照上次的单」按钮，点一下，上次那套顺序和派给谁都原样搬来，改一两处就能开工。
- **老病人要挑病症**：点名字进入。有不止一条病症时，勾选今天要做的几条（勾选顺序就是治疗顺序），点「加入今天」。病人多时顶部搜索框可以搜名字或病症，输拼音首字母也行（比如 wang 搜「王阿姨」，way 也行）。最近来过的病人排在前面。
- **常见毛病直接套模板**：如果之前存过模板（比如「肩袖常规」），点一下模板，写下病人姓名就开始，不用重新点一遍肌肉。
- **新病人**：写姓名和第一条病症名称，开始在人体上点，或者用「说一句」（见下）。输入的姓名和已有病人相同时会提醒你，可以一键打开那个人，避免建重。

### 排项目和派工

- **说一句最快**：病人页点「名单加项」，顶上的输入框把主治的话打进去（手机键盘自带语音输入：按住键盘上的麦克风说就行），比如：

  > 右肩，冈上肌松解10分钟，然后冈下肌按摩5分钟

  下面立刻显示解析出来的清单，看一眼点「加 2 项」。手法和时长跟着各自的话走，后面没说的沿用上一处。没认出来的词会标出来，跳过不加。

- 人体上点一下肌肉就是下一项，序号同时出现在模型上。手法、方向、剂量自动沿用上一项。
- **名单点选**：懒得转模型、或者要点的肌肉在深处（肩袖这类被表层肌肉盖住的），在同一个面板里搜名字或拼音首字母直接加，左右分开点。
- 点错的项目左滑去掉，**5 秒内可以点「撤销」原样放回**；顺序用右侧手柄拖动。清单里第一项没做的带 ▶ 标记，就是当前该做的。
- 要改手法/方向/剂量/派给谁，点那一行，底部升起操作卡。
- 「全部派给」把整个病人一次派给同一个人；这个病人上次派给过谁，面板最上面会有「上次：某某（照旧）」，点一下就完事。

### 交接时看什么

- **助手**：今日单顶部「派给我的」只看派给自己的人，徽标数字是没完成的项数；有新活派过来手机会震一下。
- **主治**：切到「按人」标签，谁手里几个人、做到第几项一眼看清，不用开口问。
- **上次做了什么**：加入病人时，病人名下面有一行「上次做了：……」；病人页里点「来过几次」能看到每次的日子、做了什么、完成几项。
- **备注/禁忌**：病人页点「备注」写一句（比如「高血压，别趴着按」），今日单和病人页会一直红字显示，交接不靠记性。
- **改姓名 / 归档**：病人页「改姓名」；「档案」里可归档（不再出现在加入病人列表，今日单和历史仍在）或取消归档。从没上过任何一天单的病症可在「档案」里删除。
- **纸质交班单**：今日单顶部「打印」出一页纸——按人分组的今日单，含每个人的进度和病人的红字提醒，贴前台或交接班用。

### 存模板（省掉每天重复点）

调好一套手法后，在病人页点「存为模板」起个名字。之后：

- 新病人有同样毛病：加入病人 → 从模板开始 → 写名字。
- 老病人来了新毛病：病人页点「套用模板」，作为新病症加进今天。
- 模板不想要了：今日单 → 设置 → 病症模板 → 删除。

设置里还能导出/导入整间治疗室的数据，以及恢复已归档病人。

### 做完

点每一项的「完成」。再点一次改回未完成。完成只记在今天，不会写回病症。几台手机互相实时同步，不用下拉刷新。

### 离开病人页面

如果这次改了项目内容或顺序，会问一句「今天的改动要记回病症吗」：

- **留在今天**（默认）：病症还是老样子，只是今天的单不同。
- **更新病症**：下次这个病人再来，直接按今天这套来。

### 手机上的返回键

安卓的返回键（或浏览器返回）不会退出应用，而是一层一层往回退：先关掉开着的弹窗（名单加项、备注这些），再从病人页面回到今日单。有「记回病症」提醒时，按返回先关提醒，病人页面还在；想真正回去，点提醒里的按钮。

## 数据安全

- **自动备份**：每次改动前，电脑会先把上一份数据抄进 `data/backups/`。最近 30 份分钟级备份随时可回，另外每天最早的一份保留 30 天。文件坏了、误删了，从这里面挑一份复制回 `data/clinic.json` 就能恢复。
- **手动导出**（建议每周做一次，拷到 U 盘或网盘）：今日单 → 设置 → **导出**，下载完整 JSON。也可直接复制 `data/clinic.json`。
- **导入恢复**：今日单 → 设置 → **导入**，选导出的 JSON（会二次确认并替换本机全部数据；本机需已绑定员工）。不清楚怎么操作时，直接拿备份文件覆盖 `clinic.json` 更稳妥。
- **操作记录**：谁在什么时候加了病人、改了派工、点了完成，都记在 `data/audit.log`，有疑问可以查。

## 常见问题

**手机打开很慢 / 模型加载失败？**
第一次要下载人体模型，之后走缓存。模型加载失败时下半屏清单照常可用，能派发、排序、完成。

**提示「未能保存」？**
一般是 Wi‑Fi 掉了或电脑服务没开。此时按钮保持原状，不会把没存上的操作显示成已完成。恢复网络后下拉刷新。

**过了零点还在看昨天的单？**
今日单按治疗室所在地的日历日切换，过了零点就是新的一天。昨天没做完的单不再计入今天，重新「加入病人」即可。

**想锁屏常开（前台电脑）？**
建议电脑设置自动锁屏但保持服务运行；这是局域网演示，靠门窗和电脑开机密码保护，不另设治疗室口令。

## 想上 HTTPS（可选）

手机要「添加到主屏幕」获得 App 般体验，或将来从外网访问时，需要 HTTPS：

```bash
# 生成自签证书（一次性），按提示填写，名称随便
openssl req -x509 -newkey rsa:2048 -nodes -days 825 \
  -keyout data/server.key -out data/server.crt \
  -subj "/CN=clinic"

# 用证书启动
TLS_KEY=data/server.key TLS_CERT=data/server.crt npm start
```

手机首次访问 `https://电脑IP:8787/` 会提示「不安全」，选择「继续访问」即可（自签证书的正常现象）。每台手机第一次都要确认一次。

## 数据属于谁

病人的姓名和病症是敏感健康数据，全部只存在这台电脑上，不经过任何第三方服务器。请治疗室自行做好电脑的开机密码和门窗物理安全。
