# 治疗室使用说明

这份说明写给每天用它的治疗师和助手，不涉及开发。开发相关看 README.md。

**若使用 `physio.pawpawmaster.com` 云版**：无需开治疗室电脑，先通过 Cloudflare Access 登录再使用。数据保存在 Cloudflare，与局域网版是两份独立数据；第一次迁移要明确导出/导入，不能混用地址。云端设置可查看、下载和恢复备份。部署和权限配置见 [Cloudflare部署.md](Cloudflare部署.md)，下文的电脑开机和仅存本机说明只适用于局域网版。

## 推荐的最短工作流

### 主治：照旧，只说今天的变化

首页点 **吩咐 → 选患者**，用键盘话筒或文字输入：

> 照上次，第二项改成五分钟，最后一项今天不做，交给小李

点 **预览安排**，核对沿用日期、改动、侧别、每步参数和执行者，再点 **确认派发**。未加入今天的患者在确认时才加入；选择、预览、关闭草稿都不会写入今日单。

也可以点方案简称按钮，再选整套左/右/双侧。整套换侧会保留方案里的同侧/对侧关系，关联目标也会跟着改；**文字说明中写的左右不会自动改，请核对**。

常用口令：

| 想做什么 | 说法示例 |
| --- | --- |
| 沿用最近一次实际安排 | 照上次 |
| 使用已保存的方案 | 套用A方案 |
| 修改时长、手法、侧别 | 第二项改成五分钟 / 第二项改成松解 / 第二项改成右侧 |
| 排除本次不做的步骤 | 去掉第二项 / 最后一项今天不做 |
| 调整先后 | 第二项移到第一项 / 第二项移到最后 |
| 一套交给同一人 | 交给小李 |
| 分步派工 | 左膝，股四头肌按摩8分钟给小李，然后腘绳肌松解5分钟给小王 |
| 多个目标共用手法剂量 | 左膝，股四头肌和腘绳肌各松解5分钟 |

注意：

- 「照上次」「套方案」是整单复用；已开始执行的今日单不能整单覆盖，可以明确修改尚未开始的某一项。
- 吩咐界面默认勾选 **按顺序执行**。允许现场自行安排先后的单可以取消。原有旧单不会自动改变规则；病人页 **更多 → 执行安排** 也能开启或关闭。
- 说不清、同名项目不止一项或未支持的参数会显示待确认，**不会只提交认出来的半句话**。请改清楚再预览；同名步骤用「第几项」区分。
- 「不对，改成……」、条件判断、替换设备类型等复杂口令暂不自动猜。可以重新输入正确的一句，或进入具体项目卡操作。设备参数以完整预览/设备编辑卡为准。
- 预览后若另一台手机修改了安排，会要求重新预览；此时没有重复追加，也不会覆盖对方刚完成的内容。
- 默认手法、时长和设备参数会完整显示在预览中。**默认值不是治疗建议，需由主治核对。**

### 建一次说明，以后少解释

病人页点某一步，填写 **体位、操作要点、特别交代、示范链接**，点「保存操作说明」。再存为模板，起名称和可选简称。下次套方案、照上次，说明会一起带出来。

病人页 **套用模板** 默认只把步骤加入今天、不增加病症；确实是新病症时再选择「同时新增一条病症」。它是追加步骤；要整套替换并预览，用首页吩咐。

### 执行者：只看当前卡

首页点 **我的任务**，这台手机会记住这个视图。卡片完整显示患者/床位、目标与侧别、方向/剂量、设备/机台/参数和主治说明：

- **现在可以做**：核对后按已授权的操作执行，做完点「完成并下一步」。设备项目先点「开始设备」。
- **等前一步**：会说明等哪一步、由谁做；完成后自动解锁，不用开口问进度。
- **等设备**：会显示哪位患者仍在使用；占用结束后自动恢复可操作。
- **遇到问题**：先联系卡上注明的主治，填写反馈并暂停此项。主治进入整单的该项目卡，处理后点「已处理，恢复执行」。没有岗位权限限制，治疗室需自行约定由谁处理。
- **交接与结束分开**：交接只换负责人，不释放正在使用的设备。反馈也不会假装设备已经空闲；现场处理后明确点「结束设备」或完成。

本软件是派工和交接工具，不替代临床判断、设备规范与人员培训。详细操作说明需由治疗室主治维护，新人仍须在授权和培训范围内执行。

**语音说明**：目前使用手机输入法的话筒，不是应用内自动录音。应用不调用第三方 AI；输入法是否上传语音由它自己的隐私策略决定，敏感身份信息建议直接选患者、不口述。

## 每天开始：打开派工单

1. 打开治疗室电脑（或常开的小主机）。
2. **第一次**在这台电脑上进入项目目录，打包并启动一次：

   ```bash
   npm install
   npm run build
   ./scripts/start-clinic.sh
   ```

   也可以直接 `./scripts/start-clinic.sh`：没有 `node_modules` 会先安装，没有打包产物会先 `npm run build`，然后启动服务。

3. 终端会打印类似 `clinic api http://192.168.1.5:8787` 的地址。  
   电脑上用 `http://127.0.0.1:8787/`，手机连**同一个 Wi‑Fi**，浏览器打开 `http://192.168.1.5:8787/`（以终端打印的为准）。设置页也会显示当前页面地址，方便核对。
4. **想开机后自动起来（Linux）**：在项目目录执行一次 `./scripts/install-user-systemd.sh`（路径用仓库实际位置，可用 `CLINIC_ROOT=…` 覆盖）。之后登录用户会话就会自启；看状态用 `systemctl --user status physio-dispatch`。示例单元见 `deploy/physio-dispatch.service`。
5. 局域网是明文 HTTP，**不要连公共 Wi‑Fi**。普通局域网地址用浏览器打开即可；「添加到主屏幕」只在 HTTPS 下才有完整离线缓存。第一次打开会下载人体模型（几 MB），之后有缓存，秒开。

关机不需要任何操作，数据都在电脑的 `data/clinic.json` 里。中途断电也不会丢掉已保存的内容。若没装自启，每次开机仍要再跑一次 `./scripts/start-clinic.sh`（或 `npm start`，前提是已经 `npm run build` 过）。

## 第一次使用：认人

- 第一台打开的手机**写下自己的名字**，进入今日单。
- **只有一个人的治疗室**：之后每台手机（包括微信里打开的）不再问身份，进来直接就是今日单。
- 有多人时，其余手机从名单里点「我是谁」，或填新名字。之后这台手机记住这个人，直接进今日单。
- **想加第二个名字**：设置 → 我是谁 → 新名字 → 加名字并切换（这台手机从此就是新名字）。
- 手机弄丢了或换人了：设置里把那台手机换绑到新名字即可。

## 日常流程

### 病人来了，加入今天

今日单底部「加入病人」，面板一打开光标就在搜索框里，直接打字找老病人（可输拼音首字母，比如 wang 搜「王阿姨」，肩袖相关病症也能用首字母）。往下是新病人表单，再往下是模板：

- **昨天没做完**：病人名下面有「把昨天未完成接进今天」——只带未完成项和派工，不会把昨天已完成的再当成已完成。
- **老病人照旧做**：同一位还有「照上次的单」——整单照旧（含顺序和派给谁），完成状态全部重置为未完成。和「接昨天未完成」不一样，按需要选。
- **老病人要挑病症**：点名字进入。有不止一条病症时，勾选今天要做的几条（勾选顺序就是治疗顺序），点「加入今天」。最近来过的病人排在前面。
- **常见毛病直接套模板**：如果之前存过模板（比如「肩袖常规」），点一下模板，写下病人姓名就开始，不用重新点一遍肌肉。
- **新病人**：写姓名和第一条病症名称，开始在人体上点，或者用「说一句」（见下）。输入的姓名和已有病人相同时会提醒你，可以一键打开那个人，避免建重；多病症时会留在加入面板里继续勾选。

### 排项目和派工

- **一个人时没有派工**：名单里只有一个人的话，「全部派给」「按人」这些派工界面会自动收起，但保留「我的任务 / 全部 / 按设备」；项目自动记在那个人名下，今日单行上也能直接完成当前项。从设置里加了第二个名字，按人和移交界面自动回来。

- **先有「要治的地方」**：人体点选和加项面板都要先定要治的地方（比如膝盖、腰、肩或颈）。没有时会提示，不会写进今日单。
- **加项**：病人页点「加项」打开面板，顶上的输入框就是说一句（自动弹键盘；手机键盘自带语音输入，按住键盘上的麦克风说就行），比如：

  > 右肩，冈上肌松解10分钟，然后冈下肌按摩5分钟

  下面立刻显示解析出来的清单，看一眼点「加 2 项」，或直接按键盘的完成/回车键入库。也可以直接说设备和人名，例如「冈下肌超声波8分钟派给小李」；预览会显示设备参数和派给谁。手法和时长跟着各自的话走，后面没说的沿用上一处。口语都认得：**半小时/一个小时/一刻钟**这类时长、「按一按」「松一下」「拉伸」这类说法、语音打错字（把腘绳肌说成国绳肌）都能对上。没认出来的词变成小圆片，**点一下自动填进下面的搜索框**去点名——同音错字也搜得到。已有模板 / 「照上次的单」仍是最快路径，不会被挡住。

- 人体上点一下肌肉就是下一项，序号同时出现在模型上。手法、方向、剂量自动沿用上一项。模型会把今天的单映在身上：**要治的地方是橙色、下手肌肉是深蓝色**（颜色和明度都拉开了，色弱的眼睛也分得清），左右分开；点已经亮着的肉能看到手法、剂量和谁在做，做完会变淡。单子里有深层肌肉（梨状肌、肩胛下肌、竖脊肌这类被浅层盖住的）时，模型会**自动把无关的部位调淡**，被调淡的部位也不响应点选——看得见谁就点得中谁；点在骨骼等没选项的地方时，14px 内会自动吸附到最近的选项，细肌肉不用瞄得很准；隔着骨头打到身后内脏位置的（比如点胸口戳到脊椎）不算，点哪儿就是哪儿。开完单只想看清单的话，点模型右上角「收起人体」——横幅仍显示要治哪里，这台手机会记住偏好，点「展开人体」随时回来。模型加载失败时清单照常可用，点「重试」再试一次。
- **设备模式**：人体下方切「设备」，再点人体上的部位（膝、颈等主诉区域也可以），会列出这个部位兼容的设备、具体机台和动作模板。点设备或模板一次入库；同类型多台（超声、牵引床）默认自动选，也可以点具体机台。弹力带不占机台。设备任务在清单里显示设备、机台和参数摘要；点开这一项可在设备编辑区修改参数，或一键切换具体机台/自动分配。设备项还可以开始/结束使用：同一具体机台同一时间只允许一项处于使用中；完成会自动释放。要换设备类型或动作模板，点操作卡里的「更换设备或动作」原地替换，任务顺序和派工保持不变；设备使用中需先结束。要改主诉位置或侧别时切回「手动」。
- **按设备看今天**：今日单顶部「按设备」显示全部设备；真实开始使用的机台显示「使用中」，其余有任务时按顺序显示当前/排队数，空闲和今日完成也可见。点一行直接进对应病人页。设置里的「设备台账」可看全部类型和机台，当前只读。
- **在今日单直接吩咐**：今日单头部「吩咐」→ 搜病人：今天已在单上的直接选；不在今天的选中后会先加入今日单，再继续。说一句并预览设备和派工 → 一次入库，不用先进病人页。
- **通知与角标**：设置 →「任务提醒」；HTTPS 或添加到主屏后，支持角标和页面后台时的本机通知。手机省电/锁屏仍可能延迟，局域网 HTTP 下浏览器不开放通知。
- **名单点选**：懒得转模型、或者要点的肌肉在深处（肩袖这类被表层肌肉盖住的），在同一个加项面板里搜名字或拼音首字母直接加，左右分开点。
- 点错的项目左滑去掉，**10 秒内可以点「撤销」**，派工对象和完成状态会一起带回来；顺序用右侧手柄拖动。清单里第一项没做的带 ▶ 标记，就是当前该做的。
- 换人：点这一行上的人名（或「未派」），底部只弹出在职名单，点一下就换好。要改手法/方向/剂量，再点那一行中间，升起操作卡；剂量的 +/− 点一下加减一，**按住不放连续走，松手才存一次**。点左右点反了，同一张卡上「侧别」直接切过去，不用删了重加。按摩和松解互换时调好的分钟数会保留；换成器械会重置成默认组次并提示一句。
- 「全部派给」在加项旁边，把整个病人一次派给同一个人；这个病人上次派给过谁，面板最上面会有「上次：某某（照旧）」，点一下就完事。

### 交接时看什么

- **助手/我的任务**：今日单顶部「我的任务」跨病人扁平显示自己的未完成项，按工作顺序排列；有新活派过来手机会震一下（不支持震动的手机会弹一条「有新活派给你」的提示，几秒自动消失）。进行中的项直接点行旁「完成」一下就好；设备项可先点「开始设备」，使用中再点「结束设备」，完成后会自动释放机台。和别人撞在同一张单上时会**自己重拉再试一次**，试不成才亮出失败提示，保持未完成，**未上云不算完成**。
- **今天人多**：今日单病人超过一排屏幕时会出现搜索框，输名字或拼音首字母直接跳到那位，不用滚动找。
- **主治**：切到「按人」标签，谁手里几个人、做到第几项、还剩约多少分钟一眼看清。每个人组头有「移交 N 项」，选另一位同事就能把 TA 名下所有未完成项跨病人整批移交；设备使用中的锁会释放，完成后原员工队列即时变空。
- **上次做了什么**：加入病人时，病人名下面有一行「上次做了：……」；病人页里点「来过几次」能看到每次的日子、做了什么、完成几项、这天干到几点。今日单的病人名旁还会自动标「第 N 次来」——从历史里数出来的，不用谁记。
- **备注/禁忌**：病人页点「备注」写一句（比如「高血压，别趴着按」），今日单和病人页会一直红字显示，交接不靠记性。
- **更多**：病人页次要操作在「更多」里——模板、备注、来过几次、加病症、复制、从今日单拿掉、改姓名、档案等。
- **复制**：可选「病症存档」或「今天这套」。今天这套只复制部位/手法/方向/剂量/顺序，不带派工和完成。
- **从今日单拿掉**：会先确认，确认前不会发出请求。
- **纸质交班单**：今日单顶部「打印」出一页纸——按人分组的今日单，含每个人的进度、每项「完于几点」、没做完的标「未完」，以及病人的红字提醒，贴前台或交接班用（微信里没有打印按钮，用系统浏览器打开再打）。

### 存模板（省掉每天重复点）

调好一套手法后，在病人页点「存为模板」起个名字。之后：

- 新病人有同样毛病：加入病人 → 从模板开始 → 写名字。
- 老病人来了新毛病：病人页点「套用模板」，作为新病症加进今天。
- 模板不想要了：今日单 → 设置 → 病症模板 → 删除（会先确认）。

### 常见搭配（按部位给提示）

要治的地方定了以后（比如右膝），加项面板顶部会亮出一排这个部位常用的肌肉（股四头肌、腘绳肌这些），**点一下就按主诉那一侧直接加项**，不用搜、不用转模型。已经加过的会点亮成深色。

这排默认按理疗常见组合给（膝→大腿小腿前后侧，腰→臀和核心，颈→肩背，肩→肩袖），想按自己的习惯改：今日单 → 设置 → 常见搭配 → 改搭配。编辑器里上面是「预览」（加项面板里就长这样），中间点一下去掉，下面搜到点一下加入；改完点保存搭配，全治疗室的手机都生效。想回到出厂组合，点恢复默认。

设置里还能导出/导入整间治疗室的数据，以及恢复已归档病人。

### 做完

点每一项的「完成」。再点一次改回未完成。完成只记在今天，不会写回病症。几台手机互相实时同步，不用下拉刷新。两台手机同时改同一张单时，若保存失败会提示「别人刚改过这张单，请重新拉取」，并自动重新拉取最新清单，不会停在过期清单上；完成态不会被过期的重排盖掉。

### 离开病人页面

如果这次改了项目内容或顺序，会问一句「今天的改动要记回病症吗」：

- **留在今天**（默认）：病症还是老样子，只是今天的单不同。
- **更新病症**：下次这个病人再来，直接按今天这套来。

这一轮改动只问一次：答过「留在今天」后，反复进出病人页都不会再问；之后又改了内容，才会重新问。

### 手机上的返回键

安卓的返回键（或浏览器返回）不会退出应用，而是一层一层往回退：先关掉开着的弹窗（加项、备注这些），再从病人页面回到今日单。有「记回病症」提醒时，按返回先关提醒，病人页面还在；想真正回去，点提醒里的按钮。

## 数据安全

- **自动备份**：每次改动前，电脑会先把上一份数据抄进 `data/backups/`。最近 30 份分钟级备份随时可回，另外每天最早的一份保留 30 天。文件坏了、误删了，从这里面挑一份复制回 `data/clinic.json` 就能恢复。
- **机外镜像（可选）**：电脑上设置环境变量 `BACKUP_MIRROR_DIR` 指向 U 盘或网盘同步夹后，每次自动备份时会再抄一份过去。不设则不做。
- **手动导出**（建议每周做一次，拷到 U 盘或网盘）：今日单 → 设置 → **导出**，下载完整 JSON。设置里会显示上次导出时间；超过约 7 天没导出会提醒。也可直接复制 `data/clinic.json`。微信里可能下载不了导出文件——用系统浏览器打开设置里显示的本机地址再导。
- **导入恢复**：今日单 → 设置 → **导入**，选导出的 JSON（会二次确认并替换本机全部数据；本机需已绑定员工）。不清楚怎么操作时，直接拿备份文件覆盖 `clinic.json` 更稳妥。
- **操作记录**：谁在什么时候加了病人、改了派工、点了完成，都记在 `data/audit.log`，有疑问可以查。
- **网络安全**：局域网是明文 HTTP，不要连公共 Wi‑Fi。治疗室靠门窗和电脑开机密码保护。

## 常见问题

**手机打开很慢 / 模型加载失败？**
第一次要下载人体模型，之后走缓存。模型加载失败时下半屏清单照常可用，能派发、排序、完成。

**提示「未能保存」？**
一般是 Wi‑Fi 掉了或电脑服务没开。此时按钮保持原状，不会把没存上的操作显示成已完成。恢复网络后下拉刷新。两台手机同时改同一张单失败时，会提示别人刚改过并自动重新拉取最新清单。

**过了零点还在看昨天的单？**
今日单按治疗室所在地的日历日切换，过了零点就是新的一天。昨天的单不再算今天；病人页会提示并给出「把这张单没做完的接到今天」按钮，点一下就地接续不用退出去翻找。回到今日单后，也可在「加入病人」里对那位病人点「照上次的单」整单重开。

**想锁屏常开（前台电脑）？**
建议电脑设置自动锁屏但保持服务运行；这是局域网演示，靠门窗和电脑开机密码保护。

## 想上 HTTPS（可选）

手机要「添加到主屏幕」获得完整离线缓存，或将来从外网访问时，需要 HTTPS：

```bash
# 生成自签证书（一次性），按提示填写，名称随便
openssl req -x509 -newkey rsa:2048 -nodes -days 825 \
  -keyout data/server.key -out data/server.crt \
  -subj "/CN=clinic"

# 用证书启动
TLS_KEY=data/server.key TLS_CERT=data/server.crt npm start
```

手机首次访问 `https://电脑IP:8787/` 会提示「不安全」，选择「继续访问」即可（自签证书的正常现象）。每台手机第一次都要确认一次。普通局域网 HTTP 地址用浏览器打开即可，不必强求 HTTPS。

## 数据属于谁

病人的姓名和病症是敏感健康数据，全部只存在这台电脑上，不经过任何第三方服务器。请治疗室自行做好电脑的开机密码和门窗物理安全。
