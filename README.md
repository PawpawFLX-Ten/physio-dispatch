# 治疗室派工

给治疗室几台手机共用的今日派工单：在人体上点要做的肌肉和节点，记住病症里的顺序，派给谁、完成只记在今天。

**每天用它干活的人看 [docs/治疗室使用说明.md](docs/治疗室使用说明.md)。**

**完全 Cloudflare 托管（无需电脑常开）看 [docs/Cloudflare部署.md](docs/Cloudflare部署.md)。**
云版目标站点为 `physio.pawpawmaster.com`：Worker + 静态资源 + SQLite Durable Object，保留局域网版使用方式。**当前按要求配置为公开演示，只允许虚构资料，无需邮箱或口令；页面有常驻提醒。** 共用口令和 Access 保护均可切回。云版数据保存在 Cloudflare，不适用下文局域网版“仅存本机”的数据说明；使用真实资料前必须切回保护模式。

## 少说、少点的工作流（2026-11）

- **首页「吩咐」先预览再派发**：选患者不会立即加入今天。支持「照上次，第二项改成五分钟，最后一项今天不做，交给小李」、套用方案简称、去掉/改手法或侧别/调整步骤顺序、分步派工；关闭草稿不产生派工。无法理解的范围、参数或同名步骤会阻断提交；预览后别人改单、模板或派工结果变化时必须重新预览。重复确认不会重复加项。
- **模板带操作说明、整套换侧**：项目卡可录入体位、操作要点、特别交代及 HTTPS 示范链接，保存模板时可加简称（例如 A方案）。新患者、今日套用和吩咐均可选择左/右/双侧；结构化关联目标一起映射，对侧关系保留。文字说明中的左右需人工核对。今日套用默认不新增病症，也可明确选择同时新增。
- **「我的任务」是执行卡**：完整显示患者、床位、目标侧别、方向、剂量、设备参数及说明；「完成并下一步」后自动更新。按顺序执行的单会显示「等前一步」或「等设备」，前后端共同拦截越序操作；旧单不会自动开启强制顺序。首页吩咐默认开启，可取消；病人页更多里也能设置。
- **遇到问题**：执行卡可反馈并暂停此项，今日单显示需处理数量。主治在整单项目卡中处理并恢复；设备仍在使用时不会因反馈或交接而自动释放，必须显式结束或完成。系统仍沿用原有共用名单，不新增岗位权限。
- **不接外部 AI**：规则解析与派工都在治疗室服务内运行。语音仍使用手机键盘的话筒（其识别/隐私策略由输入法提供）；程序不监听、不自动录音，也不自动生成治疗建议。

专项回归：`npm run test:workflow`（一次性数据、双手机模拟、390px 浅/深色）。支持范围与未支持的口令见使用说明；完整跨多次到院的疗程管理尚不包含在今日派工里。

## 功能一览（第二阶段新增）

- **病症模板**：调好一套手法「存为模板」，新病人一键套用；老病人新毛病「套用模板」直接挂进今天（`shared/catalog.js` 外的目标不进模板）。
- **设备与动作关联**：内置冲击波 1 台、超声 2 台、电疗 1 台、牵引床 2 台、弹力带共享、等速机 1 台；设备类型、具体机台、动作模板和人体目标共用 `shared/equipment.js`。病人页“设备”模式下点人体部位，可直接选择兼容设备/机台/动作模板；冲击波、超声、牵引床、弹力带、等速机均按设备 schema 保存参数。活动设备项可按 schema 编辑参数，一键切换具体机台或恢复自动分配，也可原地更换设备类型/动作模板，任务顺序和派工不变。
- **按设备视图**：今日单“按设备”标签显示全部设备（空闲、当前、排队、今日完成都显示）；设备任务在病人页/我的任务中可“开始使用设备/结束使用”，同一机台同一时间只允许一个未完成项处于使用中；完成会自动释放。设置页有只读设备台账。
- **设备开始/结束锁定**：设备任务有“开始使用设备/结束使用”，真实锁定具体机台；同一机台被一个未完成项使用中时，另一项开始会返回“正在被某某使用”；完成或结束立即释放。
- **今日单全局吩咐**：搜全部未归档病人，选择与预览只读；确认派发时才一次性加入今日单并写入整套安排，不用先进病人页。
- **一句话带设备和员工**：说“冈下肌超声波8分钟派给小李”，预览会显示设备、参数、派工，确认后一次入库；设备任务必须落明确左右（膝/颈作为设备区域时由所选区域决定）。
- **加项面板**：一个「加项」按钮进面板——顶上说一句（`shared/quick-order.js` 封闭词表解析器，42 目标同义词 + 设备名称 + 员工姓名 + 手法 + 方向 + 左右双 + 中文数字，语音靠手机键盘自带话筒，说完按键盘完成键直接入库），没认出的词点一下自动进搜索；往下是搜肌肉名/拼音首字母点选（不转模型，深层肌肉也点得到）；`client/src/pinyin.js`。
- **照上次的单**：一键复制病人最近一天的实际单（含顺序和派给谁），`POST /api/today/entries/repeat-last`。
- **把昨天未完成接进今天**：只带未完成项与派工，`POST /api/today/entries/carry-unfinished`（与整单照旧区分）。
- **多机冲突**：今日单条目带单调版本号；重排 / 全部派给 / 改项可带期望版本，冲突返回 409 并让客户端重拉。
- **我的任务队列**：今日单「我的任务」跨病人扁平显示自己的未完成项，按工作顺序排列；完成、开始设备、结束设备都可在队列里操作。单人治疗室也显示，所有项都算自己。
- **来过几次**：加入病人时显示「上次做了」摘要；病人页「来过几次」看全部历史（`visitHistory`，最近 12 次）。
- **打印交班单**：今日单顶部「打印」，按人分组的一页纸，含进度和红字提醒（`.print-sheet` + `@media print`）。
- **按人视图与一键移交**：主治一眼看谁手里多少活、还剩约多少分钟（没完成项的分钟数自动累加，器械按组次计不折算）；未派的排最后。每人组头可“移交 N 项”，跨病人把未完成项整批交给另一位员工，仍在使用的设备保持占用。
- **目标目录 42 个**：大腿髋（内收肌群/缝匠肌/髂腰肌/梨状肌）、小腿足（腘肌/胫骨前后肌/腓骨肌/趾长伸屈肌）、臀（臀肌群/臀中肌分立）、肩背颈（斜方肌/肩胛提肌/菱形肌/前锯肌/肩袖四肌/胸锁乳突肌）、手臂与胸腹补充（胸大/小肌、腹外斜肌、肱二/三头肌、肱桡肌、前臂伸屈肌群），映射见 `shared/body-map.js`。
- **要治的地方**：点选和加项面板都要先定「要治的地方」；没有时会提示，不会写进今日单。
- **按人数自适应派工**：名单只有一人时收起「按人」「全部派给」和行内派工，但保留「我的任务 / 全部 / 按设备」；项目自动记在那个人名下（档案带出来的项也一样），今日单行上也能直接完成当前项。加第二个名字后派工界面自动回来。
- **病人备注/禁忌**：一句话红字常驻今日单和病人页，`POST /api/patients/:id/note`。
- **找病人**：加入面板把搜索放最上面并自动聚焦；按最近来过的日子排序；支持姓名、病症、拼音首字母；同名建档有提醒，多病症时保留勾选；可改姓名、归档后不进「加入已有病人」、可恢复；未使用病症可删。
- **复制**：可选「病症存档」或「今天这套」。今天这套只复制部位/手法/方向/剂量/顺序，不带派工和完成。
- **「记回病症」每轮只问一次**：离开病人页时若这轮改了内容会问一次；答过「留在今天」后反复进出不再问，再次改动才会重新问（完成、改派不算改动）。
- **备份导出/导入**：今日单设置里导出下载 JSON、导入替换本机数据（二次确认）。
- **PWA 角标与本机提醒**：我的任务数会同步到页面标题和桌面 App 角标；HTTPS/主屏 PWA 下可在设置里开启本地通知，页面在后台但未被系统挂起时尽量提醒；锁屏推送仍受手机省电和局域网 HTTP 限制。
- **新活提醒**：我的任务徽标显示未完成数；有新活时震动提示，不支持震动的设备亮横幅；任务按全局工作顺序排列。
- **删除撤销**：左滑去掉后 10 秒内可撤销，派工对象和完成状态一起带回来。
- **确认后再动**：删除模板、从今日单拿掉都会先确认，确认前不发请求。
- **上次派给谁**：全部派给面板一键照旧。
- **病人页「更多」**：改姓名、档案、复制、从今日单拿掉等次要操作收在「更多」里。
- **安卓返回键分层**：返回键先关弹层、再退出病人页（含「记回病症」提醒），不直接退出应用；`client/src/back-layer.js`。
- **实时同步**：`GET /api/events`（SSE）数据一变推给各台手机，下拉刷新仍然可用。两台手机同时改同一张单，失败后会自动重新拉取，不会停在过期清单。
- **改完即所见**：写接口的返回值就带最新视图，前端直接用——完成一项一次往返、退出病人页不再重拉、开单进页免首次加载；人体模型解码结果常驻内存，进出病人页不重付 15 个 GLB 的解码开销。
- **今日单搜索**：病人多时（≥8 位）列表顶部出现搜索框，汉字/拼音首字母过滤。
- **人体可收起**：病人页「收起人体」把下半屏还给清单（横幅保留要治哪里），本机记忆偏好；模型加载失败可「重试」。
- **跨零点就地接续**：过了零点还在病人页时，页面上直接「把这张单没做完的接到今天」（`carryUnfinished` 也认 `entryId`），不用退回加入病人里翻找。
- **连接状态可见**：SSE 断开时今日单顶部细条提示「连接断了，正在重连」，重连成功自动补拉一次。
- **完成记时刻**：每项勾完成自动记 `completedAt`（`server/entries.js`），打印交班单按人印「完于 HH:MM」、没做完的标「未完」，病人页「来过几次」也带每天干到几点。
- **第 N 次来**：今日单病人名旁自动标「第 N 次来」，从历史天数数出来（`visitCountOf`），不用谁手工记疗程次数。
- **行内完成不再被打断**：遇 409 先重拉、活还归自己就自动再试一次（`Today.jsx` completeMine）；真失败在今日单顶部亮常驻错误条，不再只弹回按钮。
- **语音不再错认肢体**：删掉「二头肌/三头肌」裸别名（说「股二头肌」曾被静默认成手臂的肱二头肌），补「股二头肌→腘绳、小腿三头肌→腓肠」映射；裸词落进「点一下进搜索」的既定兜底（`shared/quick-order.js`）。
- **深层肌肉自动透视**：单子上有被浅层盖住的目标（梨状肌、肩胛下肌、竖脊肌等，`OCCLUDED_TARGETS`）时，模型自动把无关组调淡，颜色序号直接可见，零操作。
- **色弱可分的高亮**：要治=橙、下手=深蓝（原为橙/绿，红绿色弱易混），完成=淡蓝灰，序号标签同步换色。
- **请求体瘦身**：全局 JSON 上限 128MB→64KB，导入单独走 128MB 且先验 deviceId 再解析，未认身份的设备冻不住事件循环；导入落盘失败自动回滚内存；审计单行超 600 字折成预览，旧档留 12 份。
- **手法加「牵伸」**：第四种手法（按摩/松解/牵伸/器械），「腘绳肌拉伸十分钟」这类话不再静默落成按摩；牵伸按分钟计，换手法时调好的时长保留。
- **删除/撤销并发保护**：去掉一项也带期望版本（撞 409 自动重拉再试，别人已删就当达成）；撤销带「删完之后清单」签名，别人又动过就提示手动加回，不把项插到错位的地方。
- **SSE 契约收敛**：`shared/events.js` 双端共用事件形状（`{n, origin}`），服务端组包、前端解析同一份代码。

## 本机开发

```bash
npm install
npm test
npm run dev
```

电脑浏览器打开 http://127.0.0.1:5173/  
同一 Wi‑Fi 里的手机打开终端里打印的 `http://<电脑局域网IP>:5173/`

局域网是明文 HTTP，不要连公共 Wi‑Fi。加到主屏幕只在 HTTPS 下才有完整离线缓存；普通局域网地址用浏览器打开即可。

微信里也能直接打开：把地址发给微信或收藏，内置浏览器可用（含明文 HTTP 局域网地址）。微信里没有「加到主屏幕」的完整体验，且切走/锁屏后回来会自动重新拉一次数据；想要离线缓存和主屏图标，用系统浏览器 + HTTPS。

同一浏览器的两个标签是同一台手机。要在电脑上模拟两台手机，用两个浏览器，或给地址加上 `?device=1` 和 `?device=2`。

第一台打开的手机写下自己的名字。名单里只有一个人时，之后的手机（含微信里打开的）不再问身份，直接进今日单；多人时点「我是谁」选名字或加新名字。关掉页面后仍会记住这台手机。

## 打包后只开一个服务

```bash

```

或一键（缺依赖/缺 dist 时会先装再打包）：

```bash

```

页面和接口都在 `http://<电脑IP>:8787/`。终端会打印局域网地址。

Linux 开机自启（用户级 systemd，路径为仓库实际位置）：

```bash
./scripts/install-user-systemd.sh
# 或 CLINIC_ROOT=/path/to/repo ./scripts/install-user-systemd.sh
```

示例单元：`deploy/physio-dispatch.service`。

可选 HTTPS（手机添加到主屏幕需要）：

```bash
openssl req -x509 -newkey rsa:2048 -nodes -days 825 \
  -keyout data/server.key -out data/server.crt -subj "/CN=clinic"
TLS_KEY=data/server.key TLS_CERT=data/server.crt npm start
```

## 数据放哪儿、怎么保住

- 全部数据只在 `data/clinic.json`，不上云、不经第三方。接口开了 gzip（明文 HTTP 下首访少传约七成）；导入上限 128MB，超限会有一句能看懂的报错。
- 每次保存前自动抄一份到 `data/backups/`：最近 30 份分钟级 + 每天 1 份保留 30 天。
- 可选环境变量 `BACKUP_MIRROR_DIR`：有则在自动备份时再复制一份到该目录（缺省不启用）。
- 今日单 → 设置 → **导出** 下载完整 JSON（会记上次导出时间，超过约 7 天提醒）；**导入** 会替换本机全部数据（二次确认，需本机已绑定员工）。
- 也可直接 `GET /api/data/export?deviceId=…` / `POST /api/data/import`。
- 谁改了什么记在 `data/audit.log`（超 5MB 自动轮转）。

## 模型和图标

- 人体网格来自 BodyParts3D（© Database Center for Life Science，CC BY 4.0），原始文件在 `assets/body-source/`，页面实际加载的是 **Meshopt + 量化**（KHR_mesh_quantization）压缩版（`client/public/body/`，共约 7MB）。重新压缩：`npm run optimize:body`，压缩后 `shared/body-assets.js` 里的版本号自动更新，用于浏览器换缓存。
- Meshopt 解码器是 three 自带的纯 JS 模块（随前端包走），不再需要 Draco 的 wasm 文件；量化后的顶点在 CPU/GPU 内存里都只占一半左右。
- **按目标合并网格**：加载时把同一目标、同一侧的网格合成一件、共用一个材质（几何不克隆不改写，挂在带原始变换的节点下），draw call 从 346 路降到约 50 路；合不了的组自动退回单件网格，拾取语义不变。
- PWA 图标由 `npm run icons` 用纯 Node 生成（`scripts/make-icons.mjs`），改配色去那里改。

## 今日单上的设置

- **备份**：导出 / 导入治疗室 JSON。
- **我是谁**：换当前这台手机绑定的名字，也可填新名字加入（单人治疗室里新手机会被自动当成那个人，加第二个名字从这里进）。
- **已归档病人**：取消归档，重新出现在「加入已有病人」。
- **病症模板**：删除不用的模板（会先确认）。

病人页次要操作在「更多」里：可改姓名、归档/恢复、复制病症、从今日单拿掉（会先确认）；从没上过任何一天单的病症可在「档案」里删除。

人体上点左右侧会分开记。同一块肌肉点两次，模型上会显示两个序号。两指捏合或「靠近 / 远离」可以缩放。
