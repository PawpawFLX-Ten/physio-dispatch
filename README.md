# 治疗室派工

给治疗室几台手机共用的今日派工单：在人体上点要做的肌肉和节点，记住病症里的顺序，派给谁、完成只记在今天。

**每天用它干活的人看 [docs/治疗室使用说明.md](docs/治疗室使用说明.md)。**

## 功能一览（第二阶段新增）

- **病症模板**：调好一套手法「存为模板」，新病人一键套用；老病人新毛病「套用模板」直接挂进今天（`shared/catalog.js` 外的目标不进模板）。
- **名单加项**：不转模型，搜肌肉名或拼音首字母直接加项，深层肌肉（肩袖等被盖住的）也点得到；`client/src/pinyin.js`。
- **说一句快速开单**：`shared/quick-order.js` 的封闭词表解析器（32 目标同义词 + 手法 + 方向 + 左右双 + 中文数字），一句话变清单，语音靠手机键盘自带的话筒，不需要任何模型。
- **照上次的单**：一键复制病人最近一天的实际单（含顺序和派给谁），`POST /api/today/entries/repeat-last`。
- **把昨天未完成接进今天**：只带未完成项与派工，`POST /api/today/entries/carry-unfinished`（与整单照旧区分）。
- **多机冲突**：今日单条目带单调版本号；重排 / 全部派给 / 改项可带期望版本，冲突返回 409 并让客户端重拉。
- **派给我的一键完成**：今日单「派给我的」可对当前项直接完成（失败保持未完成）。
- **来过几次**：加入病人时显示「上次做了」摘要；病人页「来过几次」看全部历史（`visitHistory`，最近 12 次）。
- **打印交班单**：今日单顶部「打印」，按人分组的一页纸，含进度和红字提醒（`.print-sheet` + `@media print`）。
- **按人视图**：今日单第三个标签，主治一眼看谁手里多少活；未派的排最后。
- **目标目录 32 个**：大腿髋（内收肌群/缝匠肌/腘肌/髂腰肌/梨状肌）、小腿足（胫骨前后肌/腓骨肌/趾长伸屈肌）、肩背颈（斜方肌/肩胛提肌/菱形肌/前锯肌/肩袖四肌/胸锁乳突肌），映射见 `shared/body-map.js`。
- **要治的地方**：点选和名单加项都要先定「要治的地方」；没有时会提示，不会写进今日单。
- **病人备注/禁忌**：一句话红字常驻今日单和病人页，`POST /api/patients/:id/note`。
- **找病人**：按最近来过的日子排序；搜索框一直在（没有病人时不显示），支持姓名、病症、拼音首字母；同名建档有提醒，多病症时保留勾选；可改姓名、归档后不进「加入已有病人」、可恢复；未使用病症可删。
- **复制**：可选「病症存档」或「今天这套」。今天这套只复制部位/手法/方向/剂量/顺序，不带派工和完成。
- **备份导出/导入**：今日单设置里导出下载 JSON、导入替换本机数据（二次确认）。
- **派给我的**：今日单顶部切换，徽标是没完成的项数，有新活震动提示；清单第一项未完成的带 ▶ 当前标记。
- **删除撤销**：左滑去掉后 5 秒内可撤销，派工对象和完成状态一起带回来。
- **确认后再动**：删除模板、从今日单拿掉都会先确认，确认前不发请求。
- **上次派给谁**：全部派给面板一键照旧。
- **病人页「更多」**：改姓名、档案、复制、从今日单拿掉等次要操作收在「更多」里。
- **安卓返回键分层**：返回键先关弹层、再退出病人页（含「记回病症」提醒），不直接退出应用；`client/src/back-layer.js`。
- **实时同步**：`GET /api/events`（SSE）数据一变推给各台手机，下拉刷新仍然可用。两台手机同时改同一张单，失败后会自动重新拉取，不会停在过期清单。

## 本机开发

```bash
npm install
npm test
npm run dev
```

电脑浏览器打开 http://127.0.0.1:5173/  
同一 Wi‑Fi 里的手机打开终端里打印的 `http://<电脑局域网IP>:5173/`

局域网是明文 HTTP，不要连公共 Wi‑Fi。加到主屏幕只在 HTTPS 下才有完整离线缓存；普通局域网地址用浏览器打开即可。

微信里也能直接打开：把地址发给微信或收藏，内置浏览器可用（含明文 HTTP 局域网地址）。微信里没有「加到主屏幕」的完整体验，且切走/锁屏后回来会自动重新拉一次数据；想要离线缓存和主屏图标，用系统浏览器 + HTTPS。

同一浏览器的两个标签是同一台手机。要在电脑上模拟两台手机，用两个浏览器，或给地址加上 `?device=1` 和 `?device=2`。

第一台打开的手机写下自己的名字。之后的手机点「我是谁」选名字或加新名字。关掉页面后仍会记住这台手机。

## 打包后只开一个服务

```bash
npm run build
npm start
```

或一键（缺依赖/缺 dist 时会先装再打包）：

```bash
./scripts/start-clinic.sh
```

页面和接口都在 `http://<电脑IP>:8787/`。终端会打印局域网地址。

Linux 开机自启（用户级 systemd，路径为仓库实际位置）：

```bash
./scripts/install-user-systemd.sh
# 或 CLINIC_ROOT=/path/to/repo ./scripts/install-user-systemd.sh
```

示例单元：`deploy/physio-dispatch.service`。

可选 HTTPS（手机添加到主屏幕需要）：

```bash
openssl req -x509 -newkey rsa:2048 -nodes -days 825 \
  -keyout data/server.key -out data/server.crt -subj "/CN=clinic"
TLS_KEY=data/server.key TLS_CERT=data/server.crt npm start
```

## 数据放哪儿、怎么保住

- 全部数据只在 `data/clinic.json`，不上云、不经第三方。
- 每次保存前自动抄一份到 `data/backups/`：最近 30 份分钟级 + 每天 1 份保留 30 天。
- 可选环境变量 `BACKUP_MIRROR_DIR`：有则在自动备份时再复制一份到该目录（缺省不启用）。
- 今日单 → 设置 → **导出** 下载完整 JSON（会记上次导出时间，超过约 7 天提醒）；**导入** 会替换本机全部数据（二次确认，需本机已绑定员工）。
- 也可直接 `GET /api/data/export?deviceId=…` / `POST /api/data/import`。
- 谁改了什么记在 `data/audit.log`（超 5MB 自动轮转）。

## 浏览器 UI 回归（可选）

默认 `npm test` 只跑 Node 单测，不含浏览器。需要本机已开开发服务，并用支持 BiDi 的浏览器（默认连 `ws://127.0.0.1:9222/session`）：

```bash
# 终端 1：临时数据目录起开发服务
DATA_DIR=$(mktemp -d) npm run dev

# 另开带远程调试的 Chromium / Chrome，例如：
# chromium --remote-debugging-port=9222

npm run test:ui
```

环境变量：`BIDI`（BiDi WebSocket）、`CLINIC_DATA`（校验用的 clinic.json 路径）。跑不起来通常是浏览器 BiDi 未开或开发服务未在 5173。

## 模型和图标

- 人体网格来自 BodyParts3D（© Database Center for Life Science，CC BY 4.0），原始文件在 `assets/body-source/`，页面实际加载的是 Draco 压缩版（`client/public/body/`）。重新压缩：`npm run optimize:body`，压缩后 `shared/body-assets.js` 里的版本号自动更新，用于浏览器换缓存。
- Draco 解码器复制自 three 自带文件（`client/public/draco/`），前端离线可用。
- PWA 图标由 `npm run icons` 用纯 Node 生成（`scripts/make-icons.mjs`），改配色去那里改。

## 今日单上的设置

- **备份**：导出 / 导入治疗室 JSON。
- **我是谁**：换当前这台手机绑定的名字。
- **已归档病人**：取消归档，重新出现在「加入已有病人」。
- **病症模板**：删除不用的模板（会先确认）。

病人页次要操作在「更多」里：可改姓名、归档/恢复、复制病症、从今日单拿掉（会先确认）；从没上过任何一天单的病症可在「档案」里删除。

人体上点左右侧会分开记。同一块肌肉点两次，模型上会显示两个序号。两指捏合或「靠近 / 远离」可以缩放。
